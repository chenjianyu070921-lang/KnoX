# KnoX 问题 1-8 修复方案

日期：2026-08-04

本文记录评审问题列表中第 1-8 项的修复方案。第 6 项（CI/CD、Makefile 目标）按用户要求本次不修改。

## 1. 命名与死代码

- 接口类型拼写 `UploadDocRespose` → `UploadDocResponse`，同步修改 `api/doc.api`、`cmd/gateway/internal/types/types.go`、`cmd/gateway/internal/logic/uploaddoclogic.go`。
- 七牛云包重命名：`pkg/QiniuYun/quniuyun.go` → `pkg/qiniuyun/qiniuyun.go`，包名 `qiniuyun`，函数 `QiniuYunUpload` → `Upload`，符合 Go 命名规范。
- 删除从未调用的 `internal/vector/cozeloop.go`（`InitCozeLoopHandler`）及其依赖。
- 删除 `internal/vector/chunker_markdown.go` 中未使用的全局 `splitter` 变量。
- Reporter 直接返回 `internal/analytics.DashboardData`，删除 `cmd/reporter/internal/types` 与 `convertDashboard` 转换层，消除与 Gateway 重复的 DTO 定义。

遗留：Gateway 的 overview/trends/slow 响应是按事件类型聚合的结构，仍需保留薄转换层；进一步收敛可等接口稳定后统一 DTO 包。

## 2. Module path

`go.mod` 与全部 `import` 从占位符 `github.com/yourname/know` 改为真实仓库路径 `github.com/chenjianyu070921-lang/KnoX`（与 `git remote -v` 一致）。

## 3. 日志与 trace_id

- Consumer 全部 `log.Printf` 改为 go-zero `logx`，并带结构化字段：`docId`、`topic`、`partition`、`offset`。
- Gateway / Reporter 的 `main.go` 与 Reporter `svc` 统一改用 `logx`，移除 `fmt`/`log` 混用。
- 新增 `internal/requestid`：Gateway handler 将 `X-Request-Id` 注入 context；Chat/Search/DocList/Upload 的 ClickHouse 埋点 `trace_id` 改为透传真实请求 ID，不再恒为空。

## 4. 接口与参数

- 删除 `/api/v1/ping`：移除路由、handler、logic、`PingResp` 类型、`api/doc.api` 定义及 README 健康检查示例。
- Search 修复：`score` 从 Eino `Document.Score()`（`_score` 元数据）读取，不再恒为 0；`topK` 参数生效（默认 5，上限 20）。
- 文档列表修复：`DocListReq` 增加 `keyword` 字段，`DocumentRepository.List` 按 `title LIKE` 过滤，修复前端搜索参数被忽略的问题。

遗留：删除 ping 后暂无 HTTP 健康检查端点，建议后续增加 `/healthz` 并探活依赖。

## 5. 版本一致性

- `docker-compose/infra.yml`：`minio:latest` → `minio:RELEASE.2023-03-20T20-16-18Z`，`jaeger:latest` → `jaeger:1.65.0`，锁版本。
- README 技术栈与 compose 对齐：Kafka 3.7 → 4.3.1，Milvus 2.5 → 2.6.8。

## 6. CI/CD 与 Makefile

按要求本次不修改。后续建议补 `test`/`lint`/`build` 目标与 GitHub Actions（test + vet + build）。

## 7. 核心业务测试补充

- 新增 `internal/session/store_test.go`：会话创建、保存回读、TTL 过期（miniredis）。
- 新增 `internal/repository/document_test.go`：创建/查询、RequestId 幂等查询、分页 + keyword 过滤、乐观锁版本更新（sqlite）。
- 新增 `cmd/gateway/internal/logic/searchlogic_test.go`：score 元数据映射。
- 新增 `cmd/gateway/internal/logic/doclistlogic_test.go`：分页与 keyword 过滤逻辑。

遗留：上传/对话全链路单测依赖 Qiniu、Kafka、Agent 等外部组件，需先抽取接口依赖注入，列为后续工作。

验证中发现并一并修复：

- `DocumentRepository.UpdateVersion` 注释与实现不符，原来不会真正自增 `version`，导致乐观锁失效；已改为 `SET version = version + 1` 并补充测试覆盖。
- `web/src/views/DocumentPage.vue` 的 `marked` 表格渲染器签名与 v18 类型不匹配，`npm run build` 一直无法通过；已按 `TableCell` 结构调整。

## 8. Dashboard mock 误导

删除 `web/src/views/DashboardPage.vue` 中“最近错误摘要”区块及 `recentErrors` mock 逻辑，避免把演示数据展示为“基于过去 24h 日志”的真实数据。
